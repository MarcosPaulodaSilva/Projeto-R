# Projeto R — Unity

Esta pasta contém o desenvolvimento atual do jogo em **Unity 6.6 / 6000.6.0f1**, C#, 2D top-down ortogonal e pipeline Built-in.

## Abrir o projeto

1. Baixe ou clone este repositório.
2. No Unity Hub, adicione a pasta **`unity/VadroniaDemo`** — ela contém `Assets`, `Packages` e `ProjectSettings`.
3. Abra o projeto, aguarde a importação e pressione Play. A cena é criada pelo inicializador se ainda não existir.

Na máquina de Marcos, a cópia já aberta continua em `C:/Users/Marcos/Downloads/VadroniaDemo`; não é necessário movê-la.
