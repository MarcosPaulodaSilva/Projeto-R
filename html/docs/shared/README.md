# Documentação compartilhada local

Esta pasta contém cópias e resumos de informações que também são importantes para esta implementação, mesmo quando a fonte original está na raiz compartilhada do repositório.

- `PROJECT_SHARED.md`: regras e decisões compartilhadas entre plataformas.
- `lore/biblia-historia-mundo-lore-projeto-r.txt`: cópia da bíblia de lore.
- `audio/music-context.md`: cópia do contexto das músicas.
- `visual-references.md`: índice das referências visuais compartilhadas.

As fontes canônicas permanecem em `/docs/` e `/assets/`. Essas cópias existem para evitar perda de contexto quando alguém trabalha apenas dentro da pasta da plataforma.
