================================================================ 2.
IDENTIDADE E FILOSOFIA
================================================================ Projeto
R é Action RPG + Roguelike + RPG de exploração + simulação leve de
mundo, em 2D isométrico. Implementação atual: HTML5/JavaScript/Canvas
2D.

Combina exploração, combate, progressão, equipamento, companions, NPCs,
cidades/vilas vivas, relações, quests, dungeons, bosses, dia/noite,
perigos, política/nobreza e ruínas antigas.

Não criar simulador gigantesco. Profundidade vem de: SISTEMAS SIMPLES +
BOA INTEGRAÇÃO + CONSEQUÊNCIAS + COMPORTAMENTO COERENTE.

O mundo existia antes do protagonista. NPCs têm casa, trabalho,
horários, responsabilidades e perigos. O protagonista não é o escolhido.
Importância é conquistada: desconhecido → aventureiro → feitos locais →
Guilda → reconhecimento regional → reino → corte → Grandes Casas →
família real → possível importância política.

================================================================ 5.
COMBAT CORE
================================================================ Player,
enemies, companions, combat NPCs e bosses reutilizam Combat Core: Attack
Intent → Attack State → Hit Detection → Validation → Damage → Defense →
Modifiers/Status → Health → Reaction → Death/Down.

Ataques data-driven: damage, range, startup, active, recovery,
staminaCost, knockback, stagger, tags. Fases STARTUP/ACTIVE/RECOVERY;
hitbox só causa dano na fase válida; debug deve expor
fase/hitbox/hurtbox.

Stamina: max/current/cost/regen/regen delay; controla
attack/dodge/block. Block segurado consome stamina por impacto;
insuficiente = Guard Break.

Parry usa mesmo input; timing gera vantagem real. Preservar PERFECT
PARRY → RIPOSTE da 0.25.1: janela aproximada 1,35s; próximo hit válido
recebe benefício perceptível, atualmente ~35% dano final +
stagger/knockback. Balancear por teste. DEX/equipamento podem modificar
janela controladamente.

Dodge: duration, distance, stamina cost, i-frames, recovery. Testar
parede, ataque, zero stamina, multihit, hazard e transição.

Ranged: projectile
owner/team/position/velocity/damage/lifetime/collision. Flechas
respeitam cenário. Bandit Archer permanece.

Magic: reutiliza Combat Core, projectile/area/status/cooldown/mana; não
criar segundo jogo. Status compartilhado pode suportar
Burn/Poison/Slow/Stun/ Bleed/Buff/Debuff com
duration/stack/source/effect; implementar apenas quando útil.
